# 📚 Data Structures and Algorithms

Welcome to the **Data Structures and Algorithms** repository!  
Here you'll find a collection of classic and advanced problems implemented in:

- 💛 Java (complete)
- 💜 Kotlin (in progress)
- 🔵 C++ (coming soon)

> Ideal for interview prep, competitive programming, and deepening your CS knowledge.

---

## 🧠 Topics Covered

- Arrays & Strings  
- Linked Lists  
- Stacks & Queues  
- Recursion & Backtracking  
- Sorting Algorithms  
- Searching Algorithms  
- Trees & Binary Trees  
- Binary Search Trees  
- Graphs (DFS implemented, BFS coming)  
- Greedy Algorithms  
- Dynamic Programming *(planned)*  
- Hash Tables *(planned)*  
- Sliding Window / Two Pointers *(planned)*

## 📁 Folder Structure

### 🟨 Java

```bash
Java/
├── Arrays/                # Array problems and techniques
├── DFS_Search/            # DFS algorithms for graphs and trees
├── LinkedList/
│   ├── LinkedList/        # Linked list operations
│   └── listNode/          # Node structures
├── ListNode.DataStructure/ # Extra node logic (to review)
├── Queue/                 # Queue data structure problems
├── Recursion/             # Recursive algorithms and patterns
```
### 🟨 Kotlin
```bash
Kotlin/
├── Arrays/                # Kotlin array problems
├── DFS_Search/            # DFS in Kotlin
├── LinkedList/
│   ├── LinkedList/        # Kotlin-linked list logic
│   └── listNode/          # Node using Kotlin data classes
├── Queue/                 # Queue logic in Kotlin
├── Recursion/             # Recursive Kotlin solutions
├── RevisionAlgorithm/     # Mixed DSA revision in Kotlin
├── Search/                # Searching algorithms in Kotlin
├── Sorting/               # Sorting in Kotlin way
├── Stack/                 # Kotlin stack examples
└── Tree/                  # Binary trees and traversals
```
